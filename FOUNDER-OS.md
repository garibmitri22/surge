## Standing principles (enforce across ALL projects)
1. **Extractable core** — keep the reusable AI core cleanly separated from each project's business
   logic, so it lifts out clean.
2. **Model-agnostic config** — the LLM is always referenced via config, never hardcoded; upgrading
   to a better/newer model is a one-line change. Ride frontier improvements for free; always use
   the best model per job (already multi-model: Claude + Gemini).
3. **Honesty** — never fake numbers, never overclaim live features (label roadmap "coming").
4. **Build it extractable + standard** — so it's portable, future-proof, and easy to hand off.
5. **Taste + verification stay human** — the founder judges; I verify. Even with a fleet of dev
   agents, that seat is irreplaceable.
