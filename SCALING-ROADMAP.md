Turns the five locked scaling levers (MEMORY "SCALING TO $1M") into an ordered execution plan, sequenced against the build queue in `prompts/`. Read with `CEO.md` + `MEMORY.md`.

## The target + the math
$1M ARR ≈ **$83K/month**.
- All self-serve @ $999 → ~84 customers (heavy for a solo founder).
- All managed @ $3K → ~28 customers.
- **Realistic blend (the plan): ~15 managed @ $3K ($45K) + ~40 self-serve @ $999 ($40K) ≈ $85K/mo = ~$1M, ~55 logos.**
Higher ACV = fewer logos = reachable solo. That's why the managed tier is the accelerator.

## The sharpest path (one sentence)
**Pick a vertical → sell a managed tier into it → deliver with the closed loop → the learning network makes it un-copyable → agencies scale distribution.**
Recommended first vertical: **med spas** (our existing ICP; owners are a legally cold-emailable B2B list, so our own Aria sells Surge to them = dogfooding). Home services (roofing/HVAC) is the strong alternative.
